# Childhood — Утро на даче

Первый прототип прогулки от третьего лица. Ребёнок выходит с асфальтовой дороги на дачную улицу. Вдоль улицы семь участков с калитками и огородами. За дворами есть яблоневый сад, поляна и лесная тропа.

- Семь домов с крыльцами. На каждом участке три грядки с капустой, помидорами и морковью. Во дворах стоят ВАЗ‑2101 и ВАЗ‑2106, на улице — ЗАЗ‑968М.
- Соседские дети разного возраста гуляют по улице, иногда бегут и отвечают на удар. У младшего, Миши, 60 очков здоровья, у остальных — 100. На улице лежат три палки, остальные можно найти в лесу. Взрослые выходят поливать грядки либо подметать двор и потом возвращаются домой.
- Взрослый, получивший удар, перехватывает героя. Следуют три мультяшных шлепка, которые суммарно отнимают 70 очков здоровья. При нуле здоровья герой ложится и плачет 4 секунды, соперник — 15 секунд.
- Участки можно обойти и осмотреть. По улице гуляет рыжая кошка. Если подойти вплотную, она убегает.
- Дома осматриваются снаружи, машины припаркованы. Прогулка свободная, без задания и таймера.

## Запуск на Mac

1. В Unity Hub установи **Unity 6.3 LTS** для Apple Silicon. Версия проекта — **6000.3.29f1**.
2. В Unity Hub выбери **Add → Add project from disk** и открой папку `games/childhood`.
3. Открой `Assets/Childhood/Scenes/Morning.unity` и нажми **Play**. В окне **Game** щёлкни по сцене, чтобы захватить мышь.

| Управление | Действие |
| --- | --- |
| WASD или стрелки | Идти |
| Мышь | Поворот камеры |
| Shift | Бежать |
| C | Присесть или встать. На корточках двигайся через WASD |
| Пробел | Прыгнуть. В движении к низкому забору — перескочить через него |
| F или левая кнопка мыши | Удар |
| E | Подобрать палку либо открыть или закрыть калитку |
| 1 / 2 | Выбрать ладонь или подобранную палку |
| G | Выбросить палку |
| Esc | Освободить мышь |

## Как устроен прототип

`VillageMorning` собирает сцену в Play Mode из подготовленных мешей и координат мира. Геометрия окружения и модель ребёнка созданы процедурно. Персонажи используют общий скелет, отдельные циклы ходьбы и бега и короткие анимации для дел во дворе. В спарринге герои переходят в защитную стойку, двигаются приставными шагами и реагируют на попадание в момент контакта. Текстуры машин нарисованы по фотографиям [ЗАЗ‑968М](https://commons.wikimedia.org/wiki/Category:ZAZ-968M_Zaporozhets), [ВАЗ‑2101](https://commons.wikimedia.org/wiki/File:Green_VAZ-2101_at_OMMMA_2011.jpg) и [ВАЗ‑2106](https://commons.wikimedia.org/wiki/File:Lada_2106.jpg). Лес разбит на группы для отсечения вне кадра. Дома используют общий атлас с фактурами брёвен, досок, кровли, кладки и окон. Референсы фасадов — [Куплиям](https://foto.nalichniki.com/gallery.php?settlement_id=1866) и [Заозерье](https://pavpos.ru/wp-content/uploads/2019/09/%D0%A2%D0%BE%D0%BC-3-%D0%9E%D0%9A%D0%9D-%D0%93%D0%9E-%D0%9F%D0%B0%D0%B2%D0%BB%D0%BE%D0%B2%D1%81%D0%BA%D0%B8%D0%B9-%D0%9F%D0%BE%D1%81%D0%B0%D0%B4.pdf). Прозрачные стёкла ЗАЗ‑968М показывают салон. Рендеринг использует встроенный пайплайн Unity.

Если меняешь планировку или внешний вид деревни, запусти `python3 Tools/build_village.py` из этой папки. Генератор обновит геометрию, планировку и текстуры домов и машин в `Assets/Resources`. Звуки рыданий и выговора пересобираются командой `python3 Tools/build_cry.py`.

`Tools/Preview` содержит локальную браузерную версию для быстрой проверки планировки и прогулки. Собрать автономный HTML можно командой `python3 Tools/Preview/build_preview.py /path/to/childhood-preview.html`. При первой сборке скрипт скачивает фиксированную версию Three.js.
